RFCs
=====

Use RFCs to propose new public-facing or cross-cutting changes (packaging policy, CI changes, release cadence, governance). RFCs are discussion-first: open a draft PR in `rfc/` following `rfc/RFC_TEMPLATE.md`.

Process
- Draft RFC (2–4 pages), include motivation, alternatives, and rollout plan.
- Solicit feedback for 14 days by default; extend if needed.
- Final decision by maintainer; documented outcome appended to RFC.
